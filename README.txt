NETHERIA - connected game
Open index.html in a modern browser (double-click works; no server needed).

Order: The Bridge -> Citadel cutscene (tower animation, Enter/Space/Esc to skip) -> Physical Layer (topology hub) -> Transport Layer (TCP handshake) -> Packet Run (UDP vs TCP game + field guide on I) -> ending screen.
Each room unlocks the next when its task is done. Test a single scene with index.html?room=tower (or movement, physical, transport, packets).
Original standalone rooms are still in scenes/<name>/index.html.
