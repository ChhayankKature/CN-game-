PHYSICAL LAYER // HOLOGRAPHIC FIELD GUIDE
NETWORK ARCHITECTURE DATABASE · FIVE TOPOLOGIES · CORE ACCESS PROTOCOL

The Physical Layer is the foundation of the network. It carries raw bits as electrical, optical, or radio signals through physical media and hardware. The topology describes how devices and links are arranged.

01 / BUS

Every device taps into one shared backbone cable. Signals travel along the common line.

KEY RULE: backbone with terminators at both ends.

02 / STAR

Each device has a dedicated link to a central hub or switch. The switch directs traffic.

KEY RULE: devices connect to the switch, not directly to each other.

03 / RING

Each device links to two neighbours, forming one closed loop for orderly signal flow.

KEY RULE: one loop; each device has two ring links.

04 / MESH

Devices have multiple interconnections, providing alternate paths if a link fails.

KEY RULE: redundant links; in a full mesh, every pair connects.

05 / TREE

A hierarchical structure branches from a root into branches and leaves.

KEY RULE: follow parent-child branches; avoid loops and shortcuts.
